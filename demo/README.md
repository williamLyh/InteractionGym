# Demo page

`index.html` is the interactive demo published at **https://yinhongliu.com/InteractionGym/**. It plays back three recorded episodes (A, B, C) of MiniCPM-o 4.5 and a cascaded agent against the simulated user. The page is self-contained: audio and episode data are embedded. `.github/workflows/pages.yml` publishes this directory, and only this directory, to GitHub Pages on every push to `main` that changes it.
