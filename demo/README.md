# Project site

This directory is the GitHub Pages site at **https://yinhongliu.com/InteractionGym/**. `.github/workflows/pages.yml` publishes it, and only it, on every push to `main` that changes it. A tab bar at the top of every page switches between the two parts:

- **Demo** (`index.html`): the interactive demo. It plays back three recorded episodes (A, B, C) of MiniCPM-o 4.5 and a cascaded agent against the simulated user. The page is self-contained, with audio and episode data embedded.
- **Example episodes** (`examples/`): synthetic episodes from `examples/minicpmo_suite.py` (MiniCPM-o 4.5 against the simulated user, seven scenarios). They are shown in the trajectory viewer and the agent-server token-trace pages. Audio is transcoded to MP3.

To rebuild after a new run, or to refresh the tab bar:

```bash
python scripts/build_site.py --examples runs/<run>     # copy a run written by viewer.export_run into examples/
python scripts/build_site.py                           # only refresh the tab bar
```
